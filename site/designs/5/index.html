DNS, around the world

Type a name and a record type. Your browser asks three public resolvers, then asks Google Public DNS as if from 26 countries. Nothing goes through this site: no server, no cookies, no ads, no tracking.

When you press Check, your browser sends the name to dns.google, cloudflare-dns.com and dns.alidns.com, and nothing else; this page names only those hosts in its security policy.

How it works

  • The three resolvers (Google Public DNS, Cloudflare and AliDNS) answer DNS over HTTPS and allow calls from a web page. Each answers from its server nearest to you.
  • For the countries, the page sends Google Public DNS a client subnet: a /24 inside an address block that the country’s registry allocated to it, as listed by RIPEstat (the list). A name served by a CDN answers as it would for a visitor in that country. A name that does not answer by location gives the same answer everywhere.
  • So this shows what each resolver holds and what each country is told. It is not yet a lookup from each country’s own resolvers: that needs checkers placed in those countries, a later step.
  • Who owns a name: whois.tool.sovereignweb.site.
